# 问题二：源空间分类迭代

## 一键运行

在项目根目录使用专用环境执行，默认通过既有远程工具上传必要文件，服务器运行嵌套验证后下载到新时间戳目录。不会在本地执行数据分析或模型训练。

```powershell
& 'D:\Softwares\miniconda3\envs\kenny_ok\python.exe' -B problem2_iter/run_iter.py
```

服务器直接执行示例：

```bash
/home/gejw/.conda/envs/kenny_ok/bin/python -B problem2_iter/run_iter.py \
  --server --cache /home/gejw/mm/q2_20260924_mvp/final \
  --data /home/gejw/mm/q1_20260924/dataset \
  --font /home/gejw/mm/q1_20260924/assets/msyh.ttc \
  --out outputs
```

可选参数 `--cache` 指定问题二最终结果目录，`--data` 指定原始数据目录，`--out` 必须尚不存在。服务器必须同时具有问题一的源码和图形审计目录、迁移后的问题二源码以及本目录。统一入口自动上传这些必要文件，不上传历史输出。连接认证仍由既有远程工具配置，本目录不保存密码。

本次正式交付位于 `outputs/final/`，从 `report_iter.md` 阅读结论。代码重用迁移后的 `Ques2`，没有改动原问题二的算法与结果。

## 精简结构

- `run_iter.py`：远程调度、十二个外层、所有内层调参及产物保存。
- `source_features.py`：安全导入旧三源模型、训练内重新拟合、白化岭反演与源特征。
- `classifier.py`：训练内中心化、标准化、稀疏排序和三个线性分类器。
- `utils.py`：原始数据核验、间隔划分、实测诊断、图形、指标复核与报告。

## 预先固定的验证规则

- 只使用原始第一至第三脑电通道；四至六通道禁用。
- 沿用问题二按独立二十试次块处理的片段及预先固定硬质控，共三百一十九次可评估试次。测试不按预测或软质控排除。
- 跨记录：甲训练乙测试、乙训练甲测试；组内：每个记录组五折，两个任务的同序号块同时留出。
- 训练侧按原始完整留出块边界排除紧邻的一次刺激，不因边界试次质量排除而缩短间隔。嵌套内层逐一留出训练中全部可用时间块，采用相同间隔。
- 每个不同训练集合重新拟合原三源模型，禁止用包含当前验证样本的旧模型。反演协方差、任务中心化和标准化统计仅由训练样本估计。
- 传统十五维、源十二维、联合十五维。联合取十个源特征和五个头皮特征，头皮特征标准化后乘零点五。
- 每个内层重新进行一范数特征排序，选入模型的维数不超过十五；仅比较二范数逻辑回归、线性支持向量机、收缩线性判别。
- 反演强度、保留维数、分类器和超参数只由内层平均平衡准确率选择。同分时优先较少维数，再按固定候选顺序。
- 每个方案的全部外层均报告；主方案也是训练内选择，不把最高测试行改称最佳方案。

## 解释边界

小的反对称传导增益和较大条件数不是随机分类的数学证明；反演是观测的确定变换，无法无条件创造标签信息。可分性、假设高斯参照和实测分数必须分开。两个记录组已在此前分析中被研究者观察，本轮是严格折内隔离的探索性迭代，不是全新确认测试。

如果没有达到百分之六十五，报告将如实说明，不自动扩大搜索或基于测试成绩改变特征。保存的内外层模型、反演算子、划分、特征及折外预测是复现必需的正式产物。序列化模型仅加载本项目可信文件。
